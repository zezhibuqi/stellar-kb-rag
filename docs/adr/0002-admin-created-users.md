# 用户由管理员创建，不提供公开注册

设计文档 6.1 原定公开注册（默认 `employee`），经决策改为仅管理员可通过 `POST /api/users` 创建用户（含角色），前端登录页不提供注册入口；原 `/api/auth/register` 不再暴露。

**Considered Options**：保留公开注册并限制为 employee（会引入滥注册与垃圾账号风险）；由管理员创建用户（用户与权限在创建时一次确定，符合企业内部场景）。

**Consequences**：`/api/users` 需要管理员鉴权；默认测试账号（密码 `123456`）仍由种子数据创建，供验收与演示使用；认证与用户管理接口文档需同步修订。
