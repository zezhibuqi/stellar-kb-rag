# 订单结构化问答采用意图路由 + 参数化 SQL 模板

订单类问题通过 LLM 意图路由抽取结构化过滤条件，由后端以白名单参数化 SQL 模板查询 SQLite `orders` 表，结果注入上下文后生成回答；不做自由 NL2SQL，也不引入 MCP。

**Considered Options**：自由 NL2SQL（灵活但注入风险高、执行错误率高、难评测）；订单文本化入向量库（改动最小但精确查询与聚合不可靠，仅作对比基线）；MCP 工具服务器（本系统后端即 LLM 宿主，进程内调用无需协议层）。

**Consequences**：查询能力受白名单模板约束（新增问题类型需扩展模板）；每次问答增加一次路由调用；订单权限采用角色白名单（aftersale/admin）而非 role_permissions 领域表，因订单不是可灌库的文档领域。
